DATERA — LOGO KIT
=================
"Query any data. See everything." — the mark is three data bars receding into
transparency inside a rounded gradient pane (data + the glass-box identity).

PALETTE
  Indigo  #4F46E5      Violet  #8B5CF6      Ink  #12161C      Paper  #FBFCFD
  Mark gradient: #4F46E5 -> #8B5CF6 (top-left to bottom-right)
  Wordmark font: Inter, ~650 weight, -1.5 tracking

FILES

svg/  (scalable — use these for web, app, and print)
  datera-logo.svg .......... primary horizontal lockup (mark + wordmark), light
  datera-logo-dark.svg ..... lockup for dark backgrounds (white wordmark)
  datera-logo-mono.svg ..... single-color lockup (ink)
  datera-mark.svg .......... icon / mark only (full color) — works on light or dark
  datera-mark-mono.svg ..... icon, single-color ink (light backgrounds)
  datera-mark-white.svg .... icon, white with knocked-out bars (dark backgrounds)
  datera-wordmark.svg ...... wordmark only
  datera-favicon.svg ....... the mark, for favicons (identical to datera-mark)
  datera-logo-sheet.svg .... reference sheet: all variants + palette

png/  (raster — the mark, transparent background)
  favicon-16 / 32 / 48 .......... browser favicons
  apple-touch-icon-180 .......... iOS home-screen
  icon-256 / 512 / 1024 ......... app icon / store / social
  mark-mono-256 / 512 ........... single-color ink
  mark-white-256 / 512 .......... white for dark backgrounds

NOTES
- The SVG lockups load Inter via a web @import, so the wordmark renders in Inter
  in any browser. For print or font-independent use, OUTLINE the "Datera" text to
  paths in your vector editor (or ask and I'll produce outlined versions).
- PNGs are provided for the MARK only (no text), rendered pixel-perfect. PNG
  wordmark lockups were not generated here because the Inter font wasn't available
  to rasterize; use the SVG lockups, or ask for outlined-text PNG lockups.
- Everything is transparent-background where it should be.
